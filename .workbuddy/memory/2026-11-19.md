## 本地联调修复

- 移除 `wrangler.jsonc` 的 `iconv-lite` alias 空桩：mysql2 需要真实 `getDecoder/getEncoder`，否则报 `Iconv.getDecoder is not a function`。当前 pnpm 布局下 Wrangler 可直接打包真实 iconv-lite + safer-buffer；`iconv-stub.ts` 降级为历史遗留文件。
- 修复 `schema.ts` MySQL DDL：字符串主键/唯一列从 `TEXT` 改为 `VARCHAR(512)`，否则 MySQL 报 `BLOB/TEXT column 'key' used in key specification without a key length`。`store.test.ts` 新增对应断言。
